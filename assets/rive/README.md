# Buddy Rive asset slot

Place an exported Rive file named `nutri_buddy.riv` in this folder to enable native Rive rendering.
Artboard: `Buddy` (the first/default artboard also works).
State machine: default (`BuddyMachine` suggested).
Optional input names: boolean `happy`, boolean `energetic`, trigger `celebrate`.
If absent or invalid, the bundled animated Flutter buddy is displayed instead.
Create your own asset in https://rive.app; confirm licensing before using a third-party asset.
Do not rename or upload a text/PNG file as `.riv`.
